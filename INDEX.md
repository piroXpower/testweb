## 🛠️ Common Tasks

### Development
```bash
# Start development server
npm run dev

# Build for production
npm run build

# Type checking
npm run typecheck
```

### Database
```bash
# Apply schema changes
npx drizzle-kit push

# View database
npx drizzle-kit studio
```

### Customization
- **Business Info:** Edit `src/config/site.ts`
- **Colors:** Edit `src/app/globals.css`
- **Navigation:** Edit `src/config/navigation.ts`
- **Metal Rates:** Edit `src/store/useRateStore.ts`
